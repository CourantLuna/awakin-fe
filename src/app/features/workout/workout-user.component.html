INICIAR SESIÓN

Cómo ponerlo en tu iPhone en 1 minuto (Sin Mac):

  1. 1 Instala la app gratuita Scriptable desde el App Store de tu iPhone.
  2. 2 Pulsa "Copiar Código del Widget" aquí arriba, abre Scriptable, toca + (arriba a la derecha), pega el código y guárdalo con el nombre AWAKIN.
  3. 3 En la pantalla de inicio de tu iPhone, mantén presionado un espacio vacío → toca + → busca Scriptable → elige el tamaño Grande (Large) → mantén presionado el widget → Editar Widget y en Script elige AWAKIN.
